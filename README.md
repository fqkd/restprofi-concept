# RestProfi — инициативная концепция приложения

Работающий веб-прототип мобильного приложения и коммерческая презентация для УК «РестПрофи». Концепция объединяет вход в сервисы группы на уровне задач, но оставляет меню, корзину, условия заказа и правила лояльности в контексте конкретного бренда.

Это инициативная концепция ООО «ЭРГОХАВЭН», созданная на основе открытых данных. Она не является официальным продуктом УК «РестПрофи», «Питькофе», MamaDonna, «ЕстьТорт» или Cream. Прототип не выполняет реальную оплату, регистрацию, заказ или бронирование.

## Что реализовано

- выбор бренда и формата обслуживания до каталога;
- доставка, самовывоз, меню, карточка позиции и отдельная корзина бренда;
- оформление с демонстрационной ошибкой оплаты, сохранением корзины и успешным повтором;
- законченный сценарий бронирования столика;
- отдельный сценарий заказа торта;
- история, повтор заказа с проверкой доступности, предложения других брендов;
- концепция карт лояльности без утверждения общего баланса;
- hash-маршруты для прямых ссылок без серверного fallback и риска 404.

## Локальный запуск

Требуется Node.js 22+.

```bash
npm ci
npm run dev
```

Vite покажет локальный URL. Корень `/` содержит прототип, `/case/` — презентацию.

## Проверки

```bash
npm run lint
npm test
npm run test:e2e
npm run build
```

После production build:

```bash
npm run preview
QA_BASE_URL=http://127.0.0.1:4173/restprofi-concept/ node scripts/qa.mjs
```

`scripts/qa.mjs` открывает ключевые состояния на ширинах 360, 390, 430, 768 и 1440 px, проверяет ошибки браузера и горизонтальное переполнение.

## Маршруты

- `/` — оболочка интерактивного прототипа;
- `/#/brand/pitcofe/format` — выбор доставки или самовывоза;
- `/#/brand/pitcofe/menu` — меню выбранного бренда;
- `/#/booking` — бронирование;
- `/#/cake` — отдельный заказ торта;
- `/#/repeat` — повтор заказа с проверкой доступности;
- `/#/payment-error` — восстановление после ошибки;
- `/case/` — коммерческая презентация.

Состояние корзин, формата и демонстрационной ошибки хранится только в `sessionStorage` текущей вкладки.

## Сборка и публикация

`npm run build` создаёт независимый production build в `dist/`, включая `dist/case/index.html`. Base path установлен в `/restprofi-concept/`. Workflow `.github/workflows/pages.yml` запускает чистую установку, линтер, тесты, сборку и отдельный deployment GitHub Pages из ветки `main`.

Исследовательские источники и границы достоверности перечислены в [SOURCES.md](./SOURCES.md).
